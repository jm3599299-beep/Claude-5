# Política de datos de LaptopVerse

1. **Sin invenciones.** No se crean modelos, especificaciones, precios, fechas, noticias ni reseñas ficticias. El seed solo
   contiene marcas y familias (información pública estable) y datos de referencia ISO (monedas, países).
2. **Procedencia obligatoria.** Cada especificación de variante se registra en `spec_sources`. Lo no verificado se muestra
   como «No verificado».
3. **Fotografías.** Solo del modelo y generación exactos, de fabricantes/centros de prensa, con fuente y licencia. Si no
   existe, se muestra «Imagen de sustitución».
4. **Estado comercial.** «A la venta» solo con comprobación fechada y con fuente (forzado por la base de datos).
5. **Precios.** Precio real ≠ conversión. Las conversiones muestran tipo de cambio, proveedor y fecha, y no son ofertas.
6. **Noticias.** Resumen propio en español, enlace al original, sin copiar artículos, etiqueta de tipo, sin duplicados.
   Si la semana tiene pocas novedades, el Weekly lo indica.
7. **Comunidad.** Opiniones de usuarios separadas de pruebas profesionales; moderación y límites anti-spam.
